## 功能与数据语义

| 页面/模块 | 修复目的与行为 |
|---|---|
| 设备详情、运行总览、资产目录 | 仅新鲜观测参与当前健康；从未采集(MISSING)与历史过期(STALE)区分。无新鲜来源且存在后续连接失败证据时显示离线。各读端健康与过期数量采用一致规则。 |
| 接口与七日带宽 | 默认选择设备已观测接口的总接收/总发送带宽，保留单接口选择。总量以独占命名指标计算，避免SSH与SNMP两来源重复相加；不保证跨设备或逻辑/物理接口求和等于互联网出口吞吐。缺失小时为空。 |
| 监测与传感器 | 展示具体传感器数值、单位、来源与健康；设备过期时明确标记。Dell温度、PSU功耗与风扇，Cisco ASR专用传感器枚举及阈值，iMana已观测PSU功耗合计。 |
| SNMP接入 | 序列号占位NA不再充当真实身份；Dell可用服务标签单独标注。软件版本作为固件列的明确回退。缺失OID不会清空同批其他有效身份字段。 |
| 事件与告警 | 成功采集写具体健康/传感器概况；失败写具体协议及错误原因，形成去重告警。恢复关闭对应失败告警；失败事件不更新最后成功观测时间。 |
| 配置与变更 | 手动/周期只读同步；Dell/Cisco读running-config，BMC读身份与接口基线并明确范围。密码、SNMP密钥等模式在入库前脱敏；相同内容不重复生成快照；支持查看、下载和差异。 |
| 拓扑 | 使用几何形状与图例；只根据新鲜LLDP/CDP、唯一注册设备匹配建立物理边。ARP不证明物理连接；未知或歧义邻居不伪造边。 |
| 全局搜索 | Elasticsearch索引设备和端口；按当前组织过滤，端口命中再向MySQL校验归属并跳转所属设备对应接口。事件历史保留独立查询入口。搜索故障明确报错。 |
| 应用监测 | 自动选择已启用来源，首屏展示应用速率排行图与质量信息，保留协议/接口/方向及历史查询。累计计数器不冒充速率。 |
| NAT审计 | 默认全部保留历史，按平台接收时间从新到旧；可选时间范围、地址和协议，保留设备事件时间及证据缺口。游标绑定组织/设备/筛选及冻结截止。 |
| 设置 | 组织名称、默认时区、新连接采集参数、配置同步开关/周期、搜索状态与重建、本人密码修改均接实际接口。个人时区选择优先于组织默认。 |
| 合成探测 | TCP/HTTP/HTTPS/DNS/TLS实际执行、周期调度、跨副本租约、启停、归档、结果翻页。固定允许网段，HTTP不跟随重定向，TLS验证系统信任和目标身份。 |
| 导航与交互 | 可访问的侧栏滚动隐藏滚动条、收起展开及细微进入动画；尊重系统减少动画偏好。设备内接口自然排序；全局接口目录使用名称索引按字母序跨页查询，游标绑定组织与筛选；搜索定位高亮。 |
