## 仍需保留的边界

- 这是保存证据的数据库工作流，不扫描网段，也不刷新观察者 SSH 读取。来源超过15分钟时需要管理员通过现有采集入口刷新。
- 发现入口内部登记幂等且并发安全；旧人工登记入口允许重复管理地址。发现再次遇到多条同址资产时展示 CONFLICT，不能宣称全平台地址唯一。
- 历史 MAC 证据可形成弱疑似重复，界面须显示观察时间；它不证明地址现在同时在线。IP、MAC、名字、SSH key、证书均不证明物理资产唯一。
- 16条证据和1024条关联候选窗口均有上限；达到限制明确标记或拒绝，不能用成功返回宣称网段发现完整。
- IPv6 ND、SNMP ARP/FDB 复合表自动读取、Redfish UUID 自动归并、资产历史合并和关系撤销不在本轮实现范围。
- HTTP安全过滤由主任务集成；本组验证服务内角色和数据库作用域。完整服务验证、真机结果与浏览器操作分别由主任务报告汇总。
