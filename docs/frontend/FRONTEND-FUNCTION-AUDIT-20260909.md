边界：任何列表为空均显示范围/来源/错误，而不造示例数据；采集失败保留历史时间；几何拓扑线只使用服务器真实关系；应用跨接口相加有重复统计可能；NAT UDP 接收不保证完整性。当前文件审计不宣称已经逐个点击远端所有写按钮，避免创建不必要的业务记录或改动生产密码。

## 内置探测执行器的追加验证

`CheckExecutionTest` 首组 8 项 localhost 真实网络验证通过：TCP 成功/拒绝、HTTP 错误/不跟随重定向、允许网段拒绝、TLS 不受信证书失败、目标解析、DNS 与权限/版本边界。追加第 9 项同定义并发和取消后资源释放测试交由根任务完整验证。

`WorkbenchIntegrationTest` 追加两项真实 MySQL 8.4 集成测试（共用 Flyway 实际迁移）：V11 存在、两个执行器竞争同一定义仅一个可执行、租约释放与下一周期、定义版本更新后结果准确，以及 worker SQL 仅调度启用 MANUAL 定义并使新版本立即进入队列。代码已完成；运行结果由根任务统一 Maven 验证后登记，当前不预先宣称通过。

API 生成脚本 `scripts/workbench_openapi.py` 已说明 NATIVE_WORKER 与手动执行 run 端点、权限、超时、租约、固定解析地址、TLS 验证及 PASS/FAIL/UNKNOWN 含义。配置来源、搜索索引与其他设置接口的契约由对应生成器负责。

## CUA 第一轮反馈后的界面修正

- 拓扑画布从 `sourceInterface` / `targetInterface` 生成明确标签，不使用 ECharts 会显示内部 UUID 的 `{b}`。并行链路稳定分配不同曲率；缺少端口时显示友好关系类型。真实 ECharts SVG 渲染测试覆盖两条链路标签、UUID 不泄漏及曲率。
- 事件实体和配置设备列显示设备名称。名称解析仅面向当前页面至多 60 个唯一设备 ID，复用同组织/账号缓存及已加载设备；不遍历资产目录。页内事件搜索支持设备名称。
- 配置前后快照选项包含设备名称、捕获时间和中文来源；翻页后保留已选快照标签。完整协议来源保留在快照详情。
- 侧栏展示已保存的组织名称，与设置页和新建连接共用 Vue Query 设置缓存；设置不随观测的 20 秒周期轮询。保存后通过缓存失效更新。
- 被后端明确标记 `healthExcludedSensorIds` 的传感器保留严重状态，并显示“接口已管理关闭 · 低阈值仅保留证据”，其他传感器不套用排除说明。
- 探测延迟最多两位小数，自动 ms/s；监测来源展示前 6 项聚合指标，其余可展开；空聚合来源提供“查看设备传感器”链接，不编造传感器数量。
- 支持目录新增 `HARDWARE_VERIFIED_SCOPED` 的“指定机型真机已验证”标签，范围仍以服务端 notes 为准。
- 设备顶部继续由 `/devices/{id}/summary` 每 20 秒更新；测试覆盖顶部时间和在线状态刷新，同时保留当前标签页。顶部使用当前态投影 `device.lastSeen`，接入面板使用具体来源 `lastReading.observedAt`，两者原始时间差需根据真实采集投影核对。

第二版前端验证日志为 `.local/frontend-r2-tests.log`（全部组件回归）与 `.local/frontend-r2-build.log`（类型检查及生产构建）。部署与第二轮实机 CUA 结果由根任务报告记录。
