## 复现与仍需接入的能力

从项目根目录执行：

```bash
python3 scripts/mock-local.py
python3 scripts/mock-workbench.py
python3 scripts/refresh-mock-telemetry.py
python3 scripts/benchmark-workbench.py --requests 640 --concurrency 32
python3 scripts/validate-openapi.py
helm lint deploy/helm/noeriva -f deploy/helm/noeriva/ci-values.yaml
```

脚本从本地忽略的 `.env` 读取凭据，仅调用回环地址。Mock 源时间与样本不会自动持续刷新；需要新鲜观测时运行刷新脚本。NAT fixture 使用固定有效区间，复现实验按脚本保存的查询时刻验证，不能在区间外仍要求 CONFIRMED。

真实 SNMP/Redfish/LLDP 等协议适配器、采集器心跳接入、探测调度执行器、数值告警/通知、细粒度站点授权、签名与 WORM 保全仍未完成。Helm 模板已准备；实际集群的镜像仓库、密钥、数据库与存储、容量和故障恢复还需在目标环境验收。这些边界已在逐页规划、API 文档与能力矩阵中列出。
